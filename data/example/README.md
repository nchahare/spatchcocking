# Example data

This folder holds the small trial dataset used by notebooks `01` through `05`
to illustrate each step of the spatchcocking pipeline.

## Expected files

| File | Description | Generated by |
|---|---|---|
| `2025-10-22-12-30-Inner_Mask.tif` | Binary 3D TIFF inner (lumen) mask | User — 3D Slicer segmentation (see `docs/segmentation.md`) |
| `2025-10-22-12-30-Outer_Mask.tif` | Binary 3D TIFF outer (basal) mask | User — same segmentation workflow |
| `lumen.ply` | Inner surface mesh | Notebook 01 |
| `basal.ply`  | Outer (basal lamina) surface mesh | Notebook 01 |
| `lumen_curvature.ply` | Lumen mesh + curvature vertex arrays | Notebook 02 |
| `basal_curvature.ply` | Basal mesh + curvature vertex arrays | Notebook 02 |
| `lumen_thickness.ply` | Lumen mesh + thickness vertex array | Notebook 03 |
| `lumen_pHH3.ply` | Lumen mesh + pHH3 density vertex array | Notebook 04 |
| `pHH3_spots.csv` | pHH3+ cell coordinates from Imaris | User — Imaris spot detection export |

## `pHH3_spots.csv` format

Expected columns (Imaris default export):

```
Position X, Position Y, Position Z
123.4, 56.7, 89.0
...
```

Coordinates in µm, same origin and scale as the mesh.

## Notes

  derived files from the TIFF masks.
